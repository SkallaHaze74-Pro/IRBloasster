# Changelog

## 1.0.0-alpha1

- Rebuilt the project as a clean Android/Jetpack Compose application.
- Preserved the existing package name for update compatibility.
- Added LG webOS SSDP discovery, secure pairing and persistent client key.
- Added certificate fingerprint pinning after first successful connection.
- Added volume, mute, channel, media, app, input, power and text controls.
- Added Magic Remote pointer, button, movement and scrolling support.
- Added Wake-on-LAN and optional LG NEC IR fallback.
- Added Sony SIRC 12/15/20-bit encoder and manual Code Lab.
- Added configurable scenes and an in-app diagnostic log.
- Added independent premium dark/light design and adaptive launcher icon.
- Added protocol unit tests and a GitHub Actions APK artifact workflow.
