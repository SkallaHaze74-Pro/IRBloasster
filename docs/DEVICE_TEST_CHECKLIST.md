# Hardware-Testcheckliste

## LG webOS

- [ ] TV wird über SSDP gefunden.
- [ ] Manuelle IP-Verbindung funktioniert.
- [ ] TV zeigt Pairing-Anfrage.
- [ ] Bestätigung liefert einen `client-key`.
- [ ] Zweite Verbindung klappt ohne neue Bestätigung.
- [ ] Lautstärke hoch/runter funktioniert.
- [ ] Mute-Status wird live angezeigt.
- [ ] Slider setzt Lautstärke.
- [ ] Sender hoch/runter funktioniert.
- [ ] Apps werden geladen und gestartet.
- [ ] HDMI-/Eingangsliste wird geladen.
- [ ] Eingang kann gewechselt werden.
- [ ] Touchpad-Socket verbindet.
- [ ] Zeigerbewegung ist weder zu langsam noch zu schnell.
- [ ] Klick, Scrollen, Home und Back funktionieren.
- [ ] Texteingabe, Löschen und Enter funktionieren.
- [ ] Ausschalten über `ssap://system/turnOff` funktioniert.
- [ ] Wake-on-LAN funktioniert nach normalem Standby.
- [ ] WSS-Fingerprint bleibt nach Neustart stabil.

## LG IR-Fallback

- [ ] Power
- [ ] Lautstärke +
- [ ] Lautstärke −
- [ ] Mute
- [ ] Input
- [ ] Home
- [ ] D-Pad und OK
- [ ] Back

## Sony

Für jedes Kandidatenprofil die Profilnummer notieren:

- [ ] Power reagiert.
- [ ] Lautstärke + reagiert.
- [ ] Lautstärke − reagiert.
- [ ] Mute reagiert.
- [ ] Input Next reagiert.
- [ ] Kurzer Druck sendet genau eine wahrnehmbare Aktion.
- [ ] Langer Druck wiederholt in brauchbarem Tempo.

## Szenen

- [ ] Filmabend startet beide Geräte in richtiger Reihenfolge.
- [ ] Bevorzugter Eingang wird gewählt.
- [ ] Gaming startet ohne doppeltes Power-Toggle.
- [ ] Alles aus schaltet beide Geräte zuverlässig ab.
- [ ] Fehlende IP/MAC führt zu verständlicher Diagnose statt Absturz.
